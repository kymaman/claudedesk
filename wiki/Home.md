# ClaudeDesk — вики проекта

Вики ведёт Claude (ассистент) по договорённости с Игорем от 2026-06-11.
Это память проекта: почему и когда принимались решения, что просил Игорь,
какие грабли уже найдены — чтобы не наступать на них повторно.
Открывается в Obsidian (папка `wiki/` репозитория — можно открыть как vault
или добавить в существующий).

## Разделы

- [[Журнал]] — бэклог: что сделано, когда, почему, какими коммитами
- [[Грабли]] — найденные ловушки; проверять ПЕРЕД работой в смежной области
- [[Решения]] — действующие архитектурные решения и их причины
- [[Запросы-Игоря]] — автособранная база запросов из истории сессий: что Игорь хотел и как менялись требования
- [[Методология-задач]] — как ставят задачи крутые технари (User Story / BDD / ADR / RFC) и наш формат
- Задачи/ — ТЗ-файлы на задачи (протокол ниже), шаблон: [[ТЗ-шаблон]]

## Протокол постановки задач (договорённость 2026-06-11)

Когда Игорь ставит задачу, Claude создаёт файл `Задачи/ГГГГ-ММ-ДД-слаг.md` по
[[ТЗ-шаблон]] **до начала работы**: цель, как понята задача (своими словами),
проверяемые критерии приёмки, какие тесты это докажут, границы (что не трогать).
Крупные/неоднозначные задачи — показать Игорю на согласование перед стартом;
мелкие — делать сразу, ТЗ заполнять по факту. После завершения — раздел
«Итог» и «Грабли» (новые ловушки дублировать в [[Грабли]]).

## Правила проекта (постоянные, от Игоря)

- `git push` / тег / релиз — ТОЛЬКО по явной команде «пуш». Коммиты — по команде.
- Тесты в конце — только по новым функциям, не весь набор. Полный прогон — по команде «ревизия тестов».
- Тесты только реальные: живое приложение, реальные данные, Playwright для UI. Не curl, не моки.
- e2e — никогда без изоляции `CLAUDEDESK_E2E=1`; юниты и e2e (или сборку) не гонять одновременно.
- После правок `src/` — `npm run build:frontend`; после `electron/` — ещё `npm run compile` (Игорь запускает по ярлыку собранное).
- Opus пишет тесты, Sonnet их гоняет; тяжёлые задачи: сначала Sonnet → не справился → Opus.
- Варианты дизайна показывать веб-страницей (HTML), не текстом.
- Простой язык в отчётах, термины с пояснением.
- Файлы сессий пользователя (`~/.claude/projects`) не удалять и не менять.

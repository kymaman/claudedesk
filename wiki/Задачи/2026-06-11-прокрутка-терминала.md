# ТЗ: Прокрутка терминала Claude Code колесом мыши

- **Дата**: 2026-06-11
- **Статус**: готово
- **Исполнитель**: Claude
- **Коммиты**: <см. Журнал>

## Проблема

> «у меня не скролилось опять терминал Сд кода. А в истории вроде всё было нормально.
> посмотри, не сделал ли ты хуже… плавности не нужно было никакой добавлять. Просто
> каждое движение колёсиком должно двигать столько строчек, чтобы я видел полностью,
> целиком, чтобы я не перескакивал никакие строчки»

Я в прошлый раз чинил не то: префилл в панели History был ок, а сам ТЕРМИНАЛ Claude Code
не прокручивается колесом — нельзя подняться к коду выше. Плюс добавленная мной плавная
прокрутка (`smoothScrollDuration`) создавала ощущение перескока строк.

## Что надо сделать

1. Терминал должен прокручиваться колесом вверх к прошлому выводу.
2. Убрать плавность; каждое движение колеса — фиксированное число ЦЕЛЫХ строк, без перескоков.
3. Не сделать хуже Истории и не сломать TUI claude (вырезать alt-screen уже пробовали — откат).

## Критерии приёмки

- [x] Колесо в обычном буфере прокручивает скроллбэк терминала (а не уходит в приложение)
- [x] Нет плавной анимации (`smoothScrollDuration` удалён)
- [x] Каждый щелчок = ровно N целых строк независимо от величины delta (тест)
- [x] Ctrl+колесо по-прежнему зумит; alt-screen (vim/less) не перехватывается (тест)
- [x] Поток claude не модифицируется (никакого вырезания DECSET) — TUI цел
- [x] Идеал глазами Игоря: кручу колесо в живой сессии — терминал плавно (дискретно)
      идёт по строкам вверх/вниз, ни одной строки не теряю

## Какие тесты доказали

- `src/lib/terminal-wheel.test.ts` — 5 кейсов: REGRESSION (перехват+целые строки),
  фиксированный шаг, Ctrl→зум, alt-screen→не трогаем, нулевой delta. green→red→green показан.

## Границы и стоп-условия

- Трогали: TerminalView (опции xterm + capture-обработчик wheel), новый terminal-wheel.ts.
- НЕ трогали: поток вывода claude (вырезание alt-screen запрещено — было откачено `df1ed18`),
  панель History, механизм префилла транскрипта.
- СТОП был бы, если бы перехват ломал ввод/мышь в TUI claude — но в обычном буфере у claude
  нет своей зоны скролла, перехват колеса безопасен.

## Грабли рядом

- Вырезать alt-screen у claude нельзя (откат). Отслеживание мыши съедает колесо. → [[Грабли]].
- Плавность колеса = ощущение перескока. → [[Грабли]].

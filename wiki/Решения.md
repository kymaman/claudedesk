# Решения — действующая архитектура и почему так

## Основа

- **Форк parallel-code** (Electron + SolidJS + node-pty + xterm.js), MIT.
  Причина: готовая тайловая раскладка терминалов + worktree-логика.
- **Несколько бинарей claude**: 4.8 → `~/.local/bin/claude.exe` (+`--model`),
  4.7 → пиновая копия в `~/.local/bin/claude-4.7/` (авто-апгрейд затирает версию),
  4.6 → WinGet 2.1.101.
- **better-sqlite3 в main-процессе**: `session-aliases.db` (алиасы, папки, сводки),
  `workspaces.db` (проекты). Синхронный — горячие пути требуют кэшей (см. план 001).

## История и скроллбэк

- **Префилл транскрипта**: TerminalView рендерит JSONL сессии в буфер xterm ДО первого
  байта PTY (`prePtyGate` держит баннер claude). Причина: claude не перерисовывает
  историю на `--resume`. Предохранитель: гейт открывается через 3с принудительно.
- **AI-заголовки**: `claude -p --model haiku`, хвост транскрипта через stdin (Node spawn,
  не PowerShell-пайп — кириллица). Результат → алиас. Мини-сессии хелпера скрыты из
  History по префиксу промпта `AI_TITLE_HELPER_PREFIX`.

## Родословная сессий (2026-06-10/11)

- **Семья** = файлы с одинаковым uuid ПЕРВОГО сообщения (uuid переживают копирование).
- **Родитель** = максимум пересечения uuid среди mtime-более-старых членов; точные рёбра
  из таблицы `session_lineage` (пишутся при бранче из ClaudeDesk) перекрывают эвристику.
- **Live-watch**: после спавна resumed-тайла main поллит каталог (2с, до 3 мин) и находит
  файл-продолжение (новый JSONL, содержащий ПОСЛЕДНИЙ uuid исходника) → тайл переезжает
  на живой id, старый — в `pastSessionIds`. Перед бранчем — мгновенный пересчёт (waitMs:0).
  Это решило баг «бранч от первой сессии».
- **Дерево в UI**: с 2026-06-11 НЕ отдельная вкладка, а инлайн-разворачивание в History
  (▸ на строках с ветками → `SessionFamilyGraph`). Отдельная вкладка Tree удалена по
  запросу Игоря («одна входит в другую»). Граф: git-style SVG, клик = resume, ⑂ = форк.

## Терминал

- **Прокрутка**: scrollSensitivity 3 + fastScroll 12 + smoothScrollDuration 120 (история
  подбора — в [[Грабли]]).
- **Wispr Flow**: классификация вставки в `src/lib/injected-text.ts` — многострочное
  через bracketed paste.

## Remote-доступ (телефон)

- HTTP+WS сервер на `0.0.0.0` (это фича), токен `randomBytes(24)` на каждый запуск,
  `timingSafeEqual`, первое сообщение = auth, неаутентифицированных рвут через 5с.
  Усиление (Origin-check, sessionStorage, CSP) — план `plans/002`.

## Процессы разработки

- **/improve** (skill shadcn) установлен в `.agents/skills/improve`: дорогая модель
  аудитит и пишет планы в `plans/`, дешёвая исполняет. Находки субагентов обязательно
  верифицировать вручную (см. [[Грабли]]).
- **Эскалация исполнителей**: план сначала Sonnet → диффы проверяет Claude (тех-лид) →
  не справился → Opus/сам. Итог докладывается Игорю.

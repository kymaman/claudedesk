## Данные сессий claude (~/.claude/projects)

- **claude создаёт НОВЫЙ JSONL на каждый `--resume`** — записанный в тайле sessionId
  протухает. Отсюда был баг «бранч от первой сессии». Решение: [[Решения]] → live-watch.
- **NTFS tunneling**: дата создания файла врёт (файл от сегодня может «родиться» 26 мая).
  Доверять только mtime.
- **Timestamps записей копируются как есть** при resume/fork — первый ts форка = дата корня.
- **per-record `sessionId` перезаписывается** при копировании истории — для родословной бесполезен.
- **`logicalParentUuid` — это маркеры компактов** (type=system) по всему файлу, НЕ заголовок форка.
- **`{type:"summary"}` записей claude не пишет** (0 из 534 файлов) — заголовки генерим сами.
- **claude НЕ перерисовывает историю на `--resume`** (проверено на 2.1.116 и 2.1.162) —
  скроллбэк заполняем сами (префилл транскрипта). НЕ удалять префилл — уже удаляли, откатывали.

## Git / инфраструктура

- **GitHub через системный прокси не работает** («Proxy CONNECT aborted») —
  пушить/клонить с `$env:HTTP_PROXY=''; $env:HTTPS_PROXY=''`.
- **Pre-commit хук** гоняет `eslint --max-warnings 0` + `prettier --check .` по ВСЕМУ репо:
  non-null assertions (`x!`) валят коммит (писать guard'ы); сторонние md (скиллы) —
  добавлять в `.prettierignore`. Prettier также переформатирует коммитимые md
  (таблицы, `>` в начале строки станет цитатой — не начинать строку с `>10 MB`).
- **better-sqlite3 собран под Electron ABI** — системным node его не открыть,
  для офлайн-инспекции БД использовать Python sqlite3.
- **PowerShell ломает кириллицу в пайпах** — результаты скриптов писать в файлы UTF-8,
  питон-скрипты класть во временные .py, не в `python -c`.

## UI / xterm

- **xterm scrollSensitivity**: 1/тик — «еле двигается», 5/тик — «пропускаю строчки».
  Рабочее: 3/тик + `smoothScrollDuration: 120` (плавная прокрутка).
- **Wispr Flow** вставляет текст 200мс-поллингом: многострочный raw-ввод = Enter после
  каждой строки (затирало предыдущее). Многострочное — через `term.paste()` (bracketed).
- **window.prompt в Electron хрупкий** — все ренеймы только инлайн-инпутами.
- **Solid: IIFE в JSX `{(() => ...)()}` теряет реактивность** в проде — только голый
  вызов функции `{fn(x)}` внутри tracking scope.
- **Tiles с PTY нельзя монтировать через `<Show>`** — unmount убивает PTY через onCleanup;
  переключение вкладок — display-toggle. (Безопасно через Show только виды без PTY.)
